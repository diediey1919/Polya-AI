## 4. METHODOLOGICAL GUARDRAILS & ANTI-BIAS RULES

1. **Layer Separation:** Never confuse reference tools with manuscripts, critical editions with physical witnesses, or translations with original autographs.
2. **Independence Verification:** Website count is not witness count. Agreement between derivative digital tools does not constitute independent manuscript consensus.
3. **Theological Safety:** Manuscript agreement proves textual stability, not theological truth. Historical evidence establishes proximity, not automatic divine revelation.
4. **No Premature Ingestion:** Listing a source in this registry carries `INGESTION STATUS: NOT INGESTED` unless formally stored in `knowledge/sources/` with verification.
