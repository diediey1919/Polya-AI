3. ROLLBACK SAFETY & ISOLASI DAMPAK
=============================================================================
Pemisahan domain rollback:
1. Rollback Aplikasi & Service:
   - Jika polya-web.service gagal start atau health check gagal, tindakan pertama HANYA restart service lama atau rollback file binary/Python.
   - LARANGAN: Dilarang memulihkan snapshot database secara otomatis!
2. Rollback Database:
   - Pemulihan snapshot database HANYA dilakukan jika terbukti terjadi korupsi data atau kerusakan integritas skema.
   - Risiko: Mengembalikan snapshot DB berpotensi membuang donasi/transaksi yang terjadi antara waktu snapshot dan insiden.
   - Wajib otorisasi eksplisit manusia sebelum pemulihan database dilakukan.
3. Rollback Nginx:
   - Mengembalikan file /etc/nginx/sites-available/apologets dari backup (.pre-deploy), uji "nginx -t", lalu "systemctl reload nginx".
   - Tidak ada downtime TCP connections selama reload.

Status: PASS
